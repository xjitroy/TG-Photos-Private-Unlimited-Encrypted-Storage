# Owner-provided planning and design references

`TG_Photos_Master_Plan_Source.zip` preserves the owner's original PDF, DOCX and Markdown instructions.
The DOCX contains all 14 supplied UI reference images. The credential/Telegram registration screenshot
is deliberately excluded. This archive is planning evidence, not an application asset or dependency.

Run `python3 scripts/extract_references.py` after cloning to recover the documents and images into the
ignored `.toolchain/reference/` directory. Every document/image is checked against `docs/source-provenance.json`.
Historical names and requirements inside these original documents are superseded by the current
`AGENTS.md`, `docs/BRANDING.md` and owner's instructions: application name **TG Photos**, no verified
unlimited-storage claim, no APK/AAB creation or publication without explicit approval.

Use images as design references only. Do not bundle protected third-party assets in the application.
Keep the repository private; upload permission for this handoff is not permission to redistribute assets publicly.
